Publish

Approve → click → live on Instagram. Runs through your own Cloudflare Worker and Meta's official API — no passwords stored, only an official access token you control.

First-time setup (one time, ~30 minutes)
A. Instagram account
1. Instagram app → Settings → Account type → switch to Professional (Business).
2. Link it to a Facebook Page: Meta Business Suite → Settings → Linked accounts.

B. Meta developer app & token
1. Go to developers.facebook.com → My Apps → Create App → type Business → name it "Vanthara Publisher".
2. Open Tools → Graph API Explorer. Select your app on the right.
3. Click "Generate Access Token", log in, and add permissions: pages_show_list, business_management, instagram_basic, instagram_content_publish.
4. In Explorer, run GET me/accounts → copy your Page's id. Then run GET {page-id}?fields=instagram_business_account → the id inside is your IG_USER_ID.
5. Tools → Access Token Debugger → paste the token → click Extend Access Token (lasts ~60 days). The extended token is your META_TOKEN.
Note: the token expires roughly every 60 days — when the connection test fails, repeat step 5 and update the Worker secret.

C. Deploy the Worker
Follow the instructions at the top of worker-setup/vanthara-publisher-worker.js in your site folder (paste into a new Cloudflare Worker, set the 4 variables, deploy).

D. Connect below — enter the Worker URL and your Admin key, then Test connection.
